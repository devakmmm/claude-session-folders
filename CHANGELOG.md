# Changelog

## 0.1.1

- The sidebar byline is easier to spot: "by devakmmm" opens the author's website, with a LinkedIn
  link beside it.

## 0.1.0

- Folders you create, name and color, holding sessions from any project; every other session
  listed underneath, newest first.
- File sessions by hover buttons, drag and drop, right-click, or "Add This Session to a Folder…"
  from a Claude tab. Move, remove, rename, recolor and delete (with a confirmation).
- Click a session to reopen it in a Claude tab; switches to an already-open tab, offers a new
  window for another project, and asks before opening a session that is running elsewhere.
- Running sessions marked live; a notice and per-session warning before Claude Code's cleanup
  deletes old sessions.
- A generated index file (`~/.claude/session-folders.index.json`) for agents.
- Never modifies session files; writes only its two own files.
- "by devakmmm" in the sidebar header links to the source on GitHub.
