# Extension ID is devakmmm.claude-session-folders

---
status: accepted (2026-10-11); publisher `devakmmm` to be created on the Marketplace
---

The Marketplace and Open VSX identify an extension by `publisher.name`, and neither part can change
after the first upload (installs, links and settings all key off it). The publisher is `devakmmm`,
matching the GitHub account that hosts the source; the name is `claude-session-folders`, the same
descriptive pattern other Claude Code session extensions use. The display name ("Session Folders for
Claude Code") can still change, and the README states the project is not affiliated with Anthropic.
If the `devakmmm` publisher ID turns out to be taken, this ADR is updated before the first upload.
